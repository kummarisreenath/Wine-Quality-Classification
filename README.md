# 🍷 Wine Quality Classification (Multi-Model Comparison)

### 📌 Project Overview
This project solves a binary classification problem to predict wine quality (Good vs. Bad). The key focus was addressing **class imbalance** and comparing the performance of 5 different algorithms to find the best production model.

### 🛠️ Tech Stack
* **Algorithms:** Random Forest, SVM, KNN, Decision Tree, Logistic Regression
* **Libraries:** Scikit-learn, Pandas, Seaborn
* **Advanced Techniques:** SMOTE (Synthetic Minority Over-sampling Technique) for class imbalance.

### 📊 Key Results
* **Best Model:** Random Forest (Selected for production).
* **Performance:** Achieved **85%+ confidence** in predictions.
* **Impact:** Using SMOTE improved the minority class prediction by **20%**.
